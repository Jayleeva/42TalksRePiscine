# 42TalksRePiscine

Ne faites pas générer votre code.

Faites les exercices dans l'ordre.

En cas de questions, demandez d'abord à votre voisin, puis a l'équipe d'animation.

N'utilisez que les fonctions autorisées par les sujets.

Le code doit être fait en C.

La compilation ne doit afficher ni erreurs ni avertissements, même avec les flags demandes par l'école.

Pour tester la gestion de la mémoire:
````
valgrind ./yourprogram
````
